# Two Sum

Given `n` integers and a target `t`, find the two distinct indices `i < j`
such that `a[i] + a[j] == t`. Exactly one such pair exists.

## Input

```
n t
a[0] a[1] ... a[n-1]
```

`2 <= n <= 1000`, values fit in a 32-bit int.

## Output

The two indices `i j`, ascending, separated by a space.

## Example

Input:
```
4 9
2 7 11 15
```

Output:
```
0 1
```
